# Project FT-specific Python dependencies (fault-tolerant scheduler + experiments)
#
# These are dependencies USED BY this fork's fault-tolerant code (not in
# upstream vLLM) but were missing from any official requirements file,
# so a fresh `pip install -e .` would NOT install them.
#
# Discovered 2026-04-08 during P0-impl-3a investigation: ortools was missing
# in the venv, causing the Benders solver in
# vllm/v1/core/sched/benders/master.py:76 to silently fall back to greedy
# admission on every Our-System experiment. All historical Our-System data
# in results_v2/ before commit `<this commit>` may be affected.
#
# Install:
#   pip install -r requirements/ft.txt
#
# Verify:
#   python -c "from ortools.sat.python import cp_model; print('ortools OK')"
